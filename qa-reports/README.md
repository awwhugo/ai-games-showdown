# QA Reports

This section will collect practical QA evidence from AI Games Showdown projects.

## Planned report format

- **Build / environment:** Game version, operating system, and test context.
- **Test objective:** Feature or behavior under test.
- **Steps to reproduce:** Repeatable actions.
- **Expected vs. actual:** Clear comparison.
- **Evidence:** Screenshots or recordings when available.
- **Severity and status:** Impact, fix progress, and retest result.
