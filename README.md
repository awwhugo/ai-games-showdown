# AI Games Showdown 🎮

**Building games with AI. Testing what works. Sharing the results.**

AI Games Showdown is a hands-on game development series exploring what can be built with AI-assisted coding. Each project documents the idea, development process, gameplay results, technical decisions, and lessons learned.

> **Current status:** Portfolio launched · First game in planning / early development

**Project 001 · 2D Zombie Apocalypse Survival**

## 🛠️ Development approach

1. **Design** — Define a manageable game concept and playable milestones.
2. **Build** — Use AI-assisted coding while reviewing and iterating on the implementation.
3. **Test** — Document bugs, gameplay observations, and regression checks.
4. **Polish** — Improve usability, visuals, audio, and performance.
5. **Showcase** — Publish authentic gameplay, technical notes, and lessons learned.

## 🧪 Quality assurance

QA is part of the development process, not just a final step. Public case studies will cover reproducible bugs, expected vs. actual behavior, testing checklists, and fixes when those artifacts become available.
